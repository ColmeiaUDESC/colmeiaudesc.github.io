Colmeia Linux

A distribuição Linux do Colmeia UDESC. Baseada em Debian, leve, em português e com tudo o que um estudante precisa para aprender programação usando apenas software livre.

Por que Colmeia Linux

Feita para ensinar e para usar

Base Debian

Construída sobre o Debian estável: confiável, seguro e com acesso a mais de 60 mil pacotes via APT.

Pronta para programar

Python, GCC, Git, editores e ferramentas dos nossos minicursos já vêm instalados.

Em português

Idioma, teclado ABNT2 e fuso horário configurados de fábrica.

Live ISO

Dê boot pelo pendrive e use sem instalar. Gostou? Instale direto do modo live.

100% open source

Todos os scripts de build estão no GitHub. Qualquer pessoa pode gerar a mesma ISO.

Para laboratórios

Pensada para rodar bem em máquinas mais antigas de escolas e laboratórios.

Testar

Como testar numa máquina virtual

A forma mais segura de experimentar a Colmeia Linux: nada muda no seu computador.

1

VirtualBox (Windows, Linux, macOS)

Instale o VirtualBox, crie uma VM “Linux → Debian (64-bit)” com 4 GB de RAM e 20 GB de disco, e em Armazenamento selecione a ISO no drive óptico. Dê play. O VirtualBox é livre (GPL); só o Extension Pack opcional é proprietário, e ele não é necessário.

2

GNOME Boxes / virt-manager (Linux)

No Linux, use o GNOME Boxes (mais simples) ou o virt-manager: “Nova VM → Mídia de instalação local” e aponte para a ISO.

3

QEMU direto no terminal

Para quem desenvolve a distro, é o jeito mais rápido de testar cada build nova (veja o comando abaixo).

# boot da ISO em modo live (BIOS)
$ qemu-system-x86_64 -enable-kvm -m 4G -smp 2 \
    -cdrom colmeia-linux-amd64.hybrid.iso

# testar em modo UEFI (precisa do pacote ovmf)
$ qemu-system-x86_64 -enable-kvm -m 4G -smp 2 \
    -bios /usr/share/ovmf/OVMF.fd \
    -cdrom colmeia-linux-amd64.hybrid.iso

# testar a instalação num disco virtual
$ qemu-img create -f qcow2 disco.qcow2 20G
$ qemu-system-x86_64 -enable-kvm -m 4G -smp 2 \
    -hda disco.qcow2 -cdrom colmeia-linux-amd64.hybrid.iso -boot d
Contribuir

Gere a ISO você mesmo

A Colmeia Linux é construída com o live-build, a ferramenta oficial do Debian para criar imagens live. Você precisa de um sistema Debian (ou uma VM com Debian).

  • Pacotes extras ficam em config/package-lists/
  • Arquivos e configurações do sistema em config/includes.chroot/
  • Scripts de personalização em config/hooks/
  • Abra uma issue ou pull request no GitHub!
$ sudo apt install live-build git
$ git clone https://github.com/colmeiaUDESC/colmeia-linux
$ cd colmeia-linux
$ sudo lb clean
$ sudo lb config
$ sudo lb build

# a ISO aparece na pasta atual:
# live-image-amd64.hybrid.iso
